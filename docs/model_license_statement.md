## Data Governance

All data used in this project is **synthetic**, generated by scripts located in `Trace-app/data/generate_data.py`. The project contains:

- **No real PII**, customer data, or proprietary Cummins data
- Fault codes based on publicly available **SAE J1939 / OBD(-) II** standards
- Full documentation of data sourcing available in `DATA_PROVENANCE.md`

## Commercial Viability Assessment

For a production commercial deployment, **Mistral 7B (Apache 2.0)** is the recommended primary model to eliminate any license complexity entirely. That said, **Llama 3.1** remains viable for most commercial use cases under Meta's community license, which imposes minimal restrictions for organizations below the 700M MAU threshold.

**No model used in this project carries a license that would block commercial deployment.**
